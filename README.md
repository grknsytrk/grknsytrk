## About Me

I am a Computer Engineering graduate focused on building practical software systems across full-stack web development, real-time applications, and privacy-focused local AI workflows.

My work combines backend engineering, TypeScript-based web applications, WebSocket-driven real-time systems, and local LLM architectures using RAG, MCP, automation pipelines, and agentic workflows.

Currently, I am especially interested in:

- Local LLM systems and private AI workflows
- Retrieval-Augmented Generation architectures
- MCP-based AI/database integrations
- Real-time multiplayer and collaborative applications
- Production-ready backend and full-stack web systems
